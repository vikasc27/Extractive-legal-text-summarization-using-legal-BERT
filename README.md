# Extractive-legal-text-summarization-using-legal-BERT
Legal text summarization using bert is very useful application for lawyers and other who refer legal doc in short format
⚖️ Legal Document Summarizer
📖 Steps to Run in Google Colab
1️⃣ Save Files

Save all project files into a single folder.

2️⃣ Add Trained Model

Upload your trained model folder into Google Drive.

Copy the Drive path of the model folder.

3️⃣ Update Code

In the code, update:

model_path = "/content/drive/MyDrive/output_preds"


Replace /content/drive/MyDrive/output_preds with your own model path.

4️⃣ Run in Google Colab

Open a new Colab notebook.

Copy and paste the full code into a cell.

Run the cell.

5️⃣ Use the App

Upload a PDF legal document.

Click Analyze Document.

Get structured summary: Facts, Issues, Arguments, Analysis.
